## Story Description

**As an** Admin

**I want to** manage the content and elements of the Home Page sections

**So that** I can keep the website content updated, organized, and displayed correctly to website visitors.

## Acceptance Criteria

### Admin Side – Experts Section

- **Scenario 1: Manage Experts Section**
    
    - **Given** I am logged in as an Admin
        
    - **When** I access the **"Healthcare Accreditation & Quality Experts"** section
        
    - **Then** I should be able to view and edit the section title and description.
        
    - **And** the updated content should be displayed on the Landing Page.
        

### Admin Side – About Us Section

- **Scenario2: Manage About Us Section**
    
    - **Given** I am logged in as an Admin
        
    - **When** I access the **"About Us"** section
        
    - **Then** I should be able to edit the section title and content.
        
    - **And** I should be able to add, edit, delete, and reorder section elements.
        
    - **And** each element should contain a title and description.
        

### Admin Side – Our Services Section
