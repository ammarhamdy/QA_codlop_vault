## Description
The App Builder shall allow the administrator to configure the shadow appearance of the Customer Review section using the `style.shadow` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `style.shadow` attribute.
- [ ] The administrator can configure the section shadow.
- [ ] The configured shadow value is stored in the section configuration.
- [ ] The generated JSON contains the configured value in `style.shadow`.
- [ ] The Mobile App applies the configured shadow to the Customer Review section.
- [ ] Changing the section shadow does not modify other Customer Review section style properties.
