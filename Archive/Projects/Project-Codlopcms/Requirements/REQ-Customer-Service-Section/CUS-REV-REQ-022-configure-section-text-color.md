## Description
The App Builder shall allow the administrator to configure the Customer Review section text color using the `style.textColor` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `style.textColor` attribute.
- [ ] The administrator can configure the section text color.
- [ ] The configured text color is stored in the section configuration.
- [ ] The generated JSON contains the configured value in `style.textColor`.
- [ ] The Mobile App applies the configured text color to the Customer Review section text.
- [ ] Changing the text color does not modify other Customer Review section style properties.
