## Description
The App Builder shall allow the administrator to configure the review text for each customer review item using the `review` attribute within `settings.data-object`.

## Acceptance Criteria
- [ ] Each customer review item contains a `review` attribute.
- [ ] The administrator can enter or modify the review text.
- [ ] The configured review text is stored in the corresponding review item.
- [ ] The generated JSON contains the configured review text under `settings.data-object`.
- [ ] The Mobile App displays the configured review text with the corresponding customer review.
