## Description
The Admin Panel shall allow the admin to select a `shadow` style for the section container from a predefined set of options (e.g., `none`).

## Acceptance Criteria
- [ ] Admin selects `shadow` from a closed list of supported values.
- [ ] Unsupported/unrecognized values cannot be saved.
