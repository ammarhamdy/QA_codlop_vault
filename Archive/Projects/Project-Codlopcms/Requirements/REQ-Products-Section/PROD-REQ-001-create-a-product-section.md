## Description
The Admin Panel shall allow an authorized user to create a new Product Section on the Home screen.

## Acceptance Criteria
- [ ] Admin can add a new section of type `product` to the Home screen configuration.
- [ ] A unique section `id` is generated automatically upon creation.
- [ ] The newly created section is not visible to the mobile app until enabled and saved.
