## Description
The Admin Panel shall allow configuration of numeric spacing values `titleGap`, `gapTop`, and `gapBottom`.

## Acceptance Criteria
- [ ] Each field accepts a non-negative numeric value.
- [ ] Values are persisted in units consistent with mobile rendering expectations.
