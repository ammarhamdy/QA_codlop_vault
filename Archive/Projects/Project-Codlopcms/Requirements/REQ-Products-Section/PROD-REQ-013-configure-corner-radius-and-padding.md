## Description
The Admin Panel shall allow configuration of numeric geometry values `radius` and `padding` for the section container.

## Acceptance Criteria
- [ ] Each field accepts a non-negative numeric value.
- [ ] The Admin Panel enforces a sane maximum for each field to prevent layout-breaking values.
