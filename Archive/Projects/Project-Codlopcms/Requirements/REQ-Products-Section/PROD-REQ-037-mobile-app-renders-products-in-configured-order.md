## Description
The mobile application shall render resolved products in the exact order specified by `data-strings` (for the selected-products source).

## Acceptance Criteria
- [ ] Rendered order matches array order for all successfully resolved products.
- [ ] Order is not re-sorted client-side by any other criteria unless explicitly configured.
