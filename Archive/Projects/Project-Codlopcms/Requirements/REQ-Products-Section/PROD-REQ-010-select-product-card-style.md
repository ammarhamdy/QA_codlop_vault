## Description
The Admin Panel shall allow the admin to select a `productCardStyle` from a predefined, finite set of supported product card designs: `type_one`, `type_two`, `type_three`, `type_four`, `type_five`.

## Acceptance Criteria
- [ ] Admin selects a product card style from a closed list of the five supported values.
- [ ] Product card style selection is required to save/publish the section.
