## Description
Any change made in the Admin Panel to the Product Section shall become visible in the mobile application after the user refreshes (or reopens) the Home screen, without requiring an app update.

## Acceptance Criteria
- [ ] Refreshing the Home screen re-fetches the latest JSON configuration.
- [ ] Updated style/settings/product selection are reflected immediately after refresh.
