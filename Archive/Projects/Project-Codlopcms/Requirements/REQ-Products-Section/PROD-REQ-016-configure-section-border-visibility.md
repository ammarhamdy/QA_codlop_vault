## Description
The Admin Panel shall allow the admin to toggle `hideBorder` to control whether the section's outer border is visible.

## Acceptance Criteria
- [ ] `hideBorder` accepts boolean true/false.
- [ ] When `hideBorder` is true, no border is drawn around the section container.
