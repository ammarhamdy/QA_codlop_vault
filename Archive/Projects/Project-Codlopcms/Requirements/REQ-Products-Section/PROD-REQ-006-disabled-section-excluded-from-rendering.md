## Description
When a Product Section is disabled, the mobile application shall not reserve layout space for it on the Home screen.

## Acceptance Criteria
- [ ] No visual gap or placeholder remains where a disabled section would have appeared.
- [ ] Adjacent sections render as if the disabled section did not exist in the configuration.
