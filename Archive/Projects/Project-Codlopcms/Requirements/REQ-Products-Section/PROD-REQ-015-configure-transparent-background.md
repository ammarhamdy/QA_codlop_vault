## Description
The Admin Panel shall allow the admin to toggle `transparentBackground` to control whether the section background is rendered transparently.

## Acceptance Criteria
- [ ] `transparentBackground` accepts boolean true/false.
- [ ] When `transparentBackground` is true, the mobile app disregards the `background` color value for section fill.
