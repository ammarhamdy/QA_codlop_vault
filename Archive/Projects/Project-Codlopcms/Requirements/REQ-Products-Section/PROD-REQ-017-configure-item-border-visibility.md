## Description
The Admin Panel shall allow the admin to toggle `hideItemBorder` to control whether individual product card borders are visible.

## Acceptance Criteria
- [ ] `hideItemBorder` accepts boolean true/false.
- [ ] When `hideItemBorder` is true, no border is drawn around individual product cards.
