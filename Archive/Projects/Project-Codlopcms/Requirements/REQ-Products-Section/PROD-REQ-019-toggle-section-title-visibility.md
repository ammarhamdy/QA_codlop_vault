## Description
The Admin Panel shall allow the admin to toggle whether the section `title` is displayed via `showTitle`.

## Acceptance Criteria
- [ ] `showTitle` accepts boolean true/false.
- [ ] When `showTitle` is false, the mobile app does not render the title text or its allocated spacing (`titleGap`).
