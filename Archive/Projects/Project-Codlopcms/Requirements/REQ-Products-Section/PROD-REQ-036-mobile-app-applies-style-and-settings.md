## Description
The mobile application shall apply the `style` and `settings` values from the JSON to the rendered section and its product cards.

## Acceptance Criteria
- [ ] All style fields (background, colors, radius, padding, shadow, borders, spacing) are applied to the corresponding visual elements.
- [ ] All settings fields (title visibility, CTA, price display, highlight) are applied to the corresponding behavior/visibility of elements.
