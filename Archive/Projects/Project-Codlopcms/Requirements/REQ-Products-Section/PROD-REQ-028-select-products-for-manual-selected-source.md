## Description
When `productSource` is `selected_products`, the Admin Panel shall allow the admin to choose specific products to display via `data-strings`.

## Acceptance Criteria
- [ ] Admin can browse/search available products and add/remove them from the section's selection list.
- [ ] Selected product identifiers are persisted into `data-strings` as an array of strings.
