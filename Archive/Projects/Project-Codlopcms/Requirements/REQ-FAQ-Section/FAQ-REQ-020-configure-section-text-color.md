## Description
The App Builder shall allow the administrator to configure the FAQ section text color using the `style.textColor` attribute.

## Acceptance Criteria
- [ ] The FAQ section contains a `style.textColor` attribute.
- [ ] The administrator can configure the FAQ section text color.
- [ ] The configured text color is stored in the FAQ section configuration.
- [ ] The generated JSON contains the configured value in `style.textColor`.
- [ ] The Mobile App applies the configured text color to the FAQ section text when the corresponding custom text color option is enabled.
- [ ] Changing the text color does not modify other FAQ section style properties.
