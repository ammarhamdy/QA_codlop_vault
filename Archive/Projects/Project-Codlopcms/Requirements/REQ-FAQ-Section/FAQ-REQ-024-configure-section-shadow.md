## Description
The App Builder shall allow the administrator to configure the shadow appearance of the FAQ section using the `style.shadow` attribute.

## Acceptance Criteria
- [ ] The FAQ section contains a `style.shadow` attribute.
- [ ] The administrator can configure the FAQ section shadow.
- [ ] The configured shadow value is stored in the FAQ section configuration.
- [ ] The generated JSON contains the configured value in `style.shadow`.
- [ ] The Mobile App applies the configured shadow to the FAQ section.
- [ ] Changing the section shadow does not modify other FAQ section style properties.
