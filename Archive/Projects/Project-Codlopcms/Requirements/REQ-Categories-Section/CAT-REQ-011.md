## Description

The Admin Panel shall allow the admin to toggle `transparentBackground` and `hideBorder` to control whether the section background is transparent and whether the section border is visible.

## Acceptance Criteria
- [ ] `transparentBackground` accepts boolean true/false.
- [ ] `hideBorder` accepts boolean true/false.
- [ ] When `transparentBackground` is true, the mobile app disregards the `background` color value for section fill.
