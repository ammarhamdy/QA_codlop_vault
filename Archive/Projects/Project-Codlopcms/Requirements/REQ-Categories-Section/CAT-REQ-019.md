## Description

The Admin Panel shall allow the admin to toggle overall CTA visibility via `showCta`.

## Acceptance Criteria
- [ ] `showCta` accepts boolean true/false.
- [ ] When `showCta` is false, the mobile app does not render the CTA element regardless of `ctaText` value.
