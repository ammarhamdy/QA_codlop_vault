## Description

The Admin Panel shall support the creation of more than one Categories section on the same Home screen, each independently configurable.

## Acceptance Criteria
- [ ] Two or more Categories sections can co-exist with independent `id`, style, settings, and category selections.
- [ ] Each section's configuration change does not affect other Categories sections.
