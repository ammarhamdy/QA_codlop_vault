## Description

The Admin Panel shall allow the admin to select a `layout` from a predefined, finite set of supported Categories layouts (e.g., `type-two`).

## Acceptance Criteria
- [ ] Admin selects layout from a closed list of supported layout options.
- [ ] Selecting a layout updates the corresponding `layout` and `section_key` values.
- [ ] Layout selection is required to save/publish the section.
