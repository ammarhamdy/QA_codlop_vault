## Description

The Admin Panel shall allow the admin to select a `shadow` style (e.g., `none`) for the section container from a predefined set of options.

## Acceptance Criteria
- [ ] Admin selects `shadow` from a closed list of supported values.
- [ ] Unsupported/unrecognized values cannot be saved.
