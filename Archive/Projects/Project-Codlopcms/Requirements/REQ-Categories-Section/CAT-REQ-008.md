## Description

For grid-based layouts, the Admin Panel shall allow the admin to configure the number of `columns` used to render categories.

## Acceptance Criteria
- [ ] Admin can set `columns` as a positive integer.
- [ ] The Admin Panel constrains `columns` to a supported range for the selected layout.
- [ ] Column configuration only applies to layouts that support a grid arrangement.
