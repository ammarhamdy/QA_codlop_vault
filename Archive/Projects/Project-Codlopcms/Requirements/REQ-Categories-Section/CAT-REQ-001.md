## Description

The Admin Panel shall allow an authorized user to create a new Categories section on the Home screen.

## Acceptance Criteria
- [ ] Admin can add a new section of type `category` to the Home screen configuration.
- [ ] A unique section `id` is generated automatically upon creation.
- [ ] A `section_key` identifying the section variant (e.g., `type_two`) is assigned upon creation.
- [ ] The newly created section is not published/visible to the mobile app until explicitly enabled and saved.
