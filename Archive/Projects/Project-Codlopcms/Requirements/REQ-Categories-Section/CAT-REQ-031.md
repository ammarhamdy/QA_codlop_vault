## Description

The Admin Panel shall allow the admin to reorder the selected categories, and the resulting order shall be preserved in the generated JSON array (`data-strings`/`data-object`).

## Acceptance Criteria
- [ ] Admin can drag-and-drop or otherwise reorder selected categories in the UI.
- [ ] The order of elements in `data-strings`/`data-object` reflects the admin-defined order.
- [ ] The mobile app renders categories in the exact order provided in the array.
