## Description

The combination of `categoryType` and `categorySource` shall be validated for mutual consistency before the section can be saved/published.

## Acceptance Criteria
- [ ] The Admin Panel prevents saving invalid/unsupported `categoryType` + `categorySource` combinations.
- [ ] A clear validation message is shown to the admin when an inconsistent combination is selected.
