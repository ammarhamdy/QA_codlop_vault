## Description

The Admin Panel shall allow the admin to select a `highlight` mode (e.g., `none`) from a predefined set of supported highlight-badge behaviors for category items.

## Acceptance Criteria
- [ ] Admin selects `highlight` from a closed list of supported values.
- [ ] When `highlight` is `none`, no badge is rendered on any category item.
