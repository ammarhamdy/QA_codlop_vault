## Description

The Admin Panel shall allow configuration of CTA-related colors: `ctaTextColor` and `ctaBackgroundColor`, applied when the CTA is enabled.

## Acceptance Criteria
- [ ] Fields accept valid hex color values.
- [ ] CTA color fields are only meaningful/applied when `showCta` (see CAT-REQ-019) is true.
