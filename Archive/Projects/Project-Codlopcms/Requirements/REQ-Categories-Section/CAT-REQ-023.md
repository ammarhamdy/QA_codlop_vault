## Description

The Admin Panel shall allow the admin to select a `categoryType` (e.g., `third_party`) indicating the origin classification of the categories to display.

## Acceptance Criteria
- [ ] Admin selects `categoryType` from a closed list of supported values.
- [ ] `categoryType` selection affects which category-selection UI/data is presented to the admin.
