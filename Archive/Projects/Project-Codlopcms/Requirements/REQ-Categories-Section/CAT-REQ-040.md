## Description

The mobile application shall download the Home screen JSON configuration, including the Categories section, and parse it into an internal model prior to rendering.

## Acceptance Criteria
- [ ] JSON is fetched as part of the Home screen configuration retrieval.
- [ ] Parsing failures are handled per Section 5 (Error Handling) without crashing the app.
