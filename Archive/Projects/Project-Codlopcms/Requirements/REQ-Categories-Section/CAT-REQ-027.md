## Description

The Admin Panel shall allow the admin to choose which specific categories, from the configured `categorySource`, are displayed within the section.

## Acceptance Criteria
- [ ] Admin can browse/search available categories from the selected source.
- [ ] Admin can add and remove categories from the section's selection list.
- [ ] Selected category identifiers are persisted into `data-strings` (external) or `data-object` (internal).
