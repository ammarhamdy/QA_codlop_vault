## Description

The application shall provide a cart screen where users can review products they intend to purchase.

## Acceptance Criteria

-  Users can access the Cart screen from the application navigation.
    
-  The Cart screen displays all products currently added to the cart.
    
-  Each cart item displays the product name, image, price, and quantity.
    
-  The Cart screen displays the total cart amount.
    
-  The Cart screen updates when products are added, updated, or removed.
    
-  The application displays an appropriate message when the cart is empty.
    
-  Selecting a cart item navigates the user to the Product Details screen.
