## Description

The application shall allow users to search for products available in the catalog. Search results shall be based on product data retrieved from the Zid API.

## Acceptance Criteria

-  Users can access the search screen from the Home Screen.
    
-  Users can enter a search keyword.
    
-  The application performs a search using the entered keyword.
    
-  Search results display products matching the search criteria.
    
-  Each search result displays the product name, image, and price.
    
-  Users can modify the search keyword and receive updated results.
    
-  An appropriate message is displayed when no matching products are found.
    
-  An appropriate error message is displayed when the search request fails.
    
-  Selecting a product from the search results navigates the user to the Product Details screen.
