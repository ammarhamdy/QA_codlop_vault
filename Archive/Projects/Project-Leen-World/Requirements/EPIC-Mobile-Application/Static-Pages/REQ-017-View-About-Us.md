## Description

The application shall provide an About Us page that displays information about the organization. The page content shall be retrieved from the Codlop API.

## Acceptance Criteria

-  Users can access the About Us page from the Profile screen.
    
-  The About Us page retrieves its content from the Codlop API.
    
-  The About Us page displays the content returned by the API.
    
-  The page supports scrolling when content exceeds the screen height.
    
-  An appropriate loading indicator is displayed while content is being retrieved.
    
-  An appropriate error message is displayed when content retrieval fails.
    
-  The displayed content matches the latest content configured by the admin panel.
