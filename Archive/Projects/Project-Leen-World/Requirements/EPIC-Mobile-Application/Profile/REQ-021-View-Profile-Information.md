## Description

The application shall provide a Profile screen where users can view their personal account information.

## Acceptance Criteria

-  Users can access the Profile screen from the application navigation.
    
-  The Profile screen displays the user's name.
    
-  The Profile screen displays the user's phone number.
    
-  The Profile screen displays the user's email address.
    
-  The Profile screen displays the user's address information, if available.
    
-  The application displays the latest profile information available for the user.
    
-  An appropriate loading indicator is displayed while profile information is being retrieved.
    
-  An appropriate error message is displayed when profile information cannot be retrieved.
