## Description

The application shall display product categories retrieved from the Zid API, allowing users to browse products by category.

## Acceptance Criteria

-  Categories are retrieved from the Zid API.
    
-  All categories returned by the API are displayed.
    
-  Each category displays its configured name and image, if available.
    
-  Categories are displayed in the order returned by the API.
    
-  Users can select a category.
    
-  Selecting a category navigates the user to the corresponding category products screen.
    
-  The application displays an appropriate message when no categories are available.
    
-  The application handles category retrieval failures gracefully.
