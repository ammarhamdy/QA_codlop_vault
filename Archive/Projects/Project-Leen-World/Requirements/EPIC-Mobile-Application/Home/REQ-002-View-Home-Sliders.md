## Description

The application shall display promotional sliders on the Home Screen based on content configured in the admin panel and retrieved from the Codlop API.

## Acceptance Criteria

-  Slider content is retrieved from the Codlop API.
    
-  All active sliders returned by the API are displayed.
    
-  Each slider displays its configured image.
    
-  Sliders are displayed in the order configured by the admin panel.
    
-  Users can swipe between sliders.
    
-  Selecting a slider performs its configured action, if one exists.
    
-  The application handles missing or invalid slider images gracefully.
