## Description

The application shall allow users to navigate to the Product Details screen from products displayed on the Home screen.

## Acceptance Criteria

-  Products displayed on the Home screen are selectable.
    
-  Selecting a product navigates the user to the Product Details screen.
    
-  The selected product's information is displayed on the Product Details screen.
    
-  Navigation occurs without requiring the user to restart or reload the application.
