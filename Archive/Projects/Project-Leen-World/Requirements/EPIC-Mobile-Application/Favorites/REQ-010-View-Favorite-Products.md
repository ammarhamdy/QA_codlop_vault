## Description

The application shall allow users to view products they have previously marked as favorites.

## Acceptance Criteria

-  Users can access the Favorites screen from the application navigation.
    
-  The Favorites screen displays all products marked as favorites.
    
-  Each favorite product displays its name, image, and price.
    
-  Favorite products remain available after restarting the application.
    
-  The application displays an appropriate message when the favorites list is empty.
    
-  Selecting a favorite product navigates the user to the Product Details screen.
    
-  The Favorites screen updates when products are added to or removed from favorites.
