# Preconditions

# Steps
1. Note the current total, active, and inactive counts.  
2. Add a new feature.  
3. Delete a feature.  
4. Verify the statistics.
# Expected Result
-After adding a feature, the total count and corresponding active/inactive count should be updated correctly. After deleting a feature, the total count and corresponding active/inactive count should be decreased correctly.
