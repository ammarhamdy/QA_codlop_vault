# Steps
1. Enter a value in the **Title** field below the minimum  or exceeding the maximum allowed length. 
2. Verify the validation message.

# Expected Result
-A validation message should be displayed when the Title is below the minimum allowed length or exceeds the maximum allowed length. A valid value within the allowed range should be accepted.
