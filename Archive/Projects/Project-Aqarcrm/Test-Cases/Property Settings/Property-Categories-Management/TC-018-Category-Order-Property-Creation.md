# Preconditions
-At least two active property categories exist and their display order has been changed.
# Steps
1. Change the order of the categories from **Property Settings**.   
2. Navigate to properties & click **Add Property**.  
3. Open the **Property Category** dropdown.  
4. Review the category order.
# Expected Result
-The active property categories are displayed in the **same order configured in Property Settings**.
