# Steps
1. Apply one or more filters (e.g., Property Purpose, City, Property Type, Price Range).  
2. Verify the filtered results.  
3. Switch from **Grid View** to **List View** & back from **List View** to **Grid View**.
# Expected Result
-The selected view is applied successfully, and the filtered results remain unchanged. All applied filters are retained after switching between views.
