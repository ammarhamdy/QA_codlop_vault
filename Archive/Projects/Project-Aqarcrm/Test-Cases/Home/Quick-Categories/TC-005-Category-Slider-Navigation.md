# Preconditions
-User is on the Home page, and the category slider contains multiple categories.
# Steps
1. Navigate to the category slider.  
2. Click the **Next** button repeatedly.  
3. Verify that the next categories are displayed.  
4. Click the **Previous** button repeatedly.  
5. Verify that the previous categories are displayed.
# Expected Result
-Clicking the **Next** button displays the next set of categories, and clicking the **Previous** button displays the previous set. The slider navigates smoothly without skipping or duplicating categories, and users cannot navigate beyond the first or last category.
