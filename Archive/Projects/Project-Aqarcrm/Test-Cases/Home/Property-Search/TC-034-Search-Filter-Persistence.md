# Preconditions
-User is on the Home page.
# Steps
1. Apply one or more search filters.  
2. Click **Search**.  
3. After the search results page opens, click the browser's **Back** button or return to the Home page.
# Expected Result
-All previously selected search filters remain selected and retain their values.
