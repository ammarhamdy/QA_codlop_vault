## Story Description
**As a** website visitor  
**I want to** view the organization's contact information  
**So that** I can contact the organization through the available communication channels

## Acceptance Criteria
- **Scenario 1:** Given the Contact Us page is loaded -> When the contact information section is displayed -> Then the email address is visible
    
- **Scenario 2:** Given the Contact Us page is loaded -> When the contact information section is displayed -> Then the phone number is visible
    
- **Scenario 3:** Given the Contact Us page is loaded -> When the contact information section is displayed -> Then the WhatsApp number is visible
    
- **Scenario 4:** Given the Contact Us page is loaded -> When the contact information section is displayed -> Then the address is visible
