# كراسة الشروط والمواصفات الفنية لتطوير تطبيق الأسرة

---
## أولاً: معلومات المنصة ونطاق التشغيل

- [ ] **التطبيقات:** تطبيق هواتف ذكية لنظامي (iOS & Android) + تطبيق ويب / لوحة تحكم للمشرفين.
- [ ] **دعم الأجهزة:** يجب أن يتوافق التطبيق ولوحة التحكم بشكل كامل مع الشاشات المختلفة (جوالات، آيباد / تابلت، شاشات كبيرة).
- [ ] **لغة التطبيق:** اللغة العربية كلغة أساسية.

---

## ثانياً: التسجيل والأمان وإدارة العضوية

### 1. تسجيل الدخول والتفعيل
- [ ] **الدخول عبر رقم الجوال:** باستخدام رمز التحقق (SMS OTP).
- [ ] **المصادقة الحيوية:** دعم الدخول المباشر بالبصمة / الوجه (Biometrics) مع خاصية "البقاء متصلاً".
- [ ] **تصفح الزائر:** يُسمح للزائر بتصفح قسم الأخبار والنسب فقط، بينما تُحجب الشجرة والدليل حتى يتم تفعيل العضوية.

### 2. نظام الموافقة على العضوية
- [ ] إرسال طلب انضمام يمر على المشرفين للتحقق من صلة القرابة.
- [ ] إرسال ==رسائل نصية== / إشعارات تلقائية لطالب الانضمام توضح حالة الطلب (قيد المراجعة / تم القبول).

### 3. توزيع الصلاحيات
- [ ] إمكانية تعيين مشرفين مع منحهم صلاحيات لتحديث البيانات وتوثيق المواليد / الوفيات / الزوجات حسب الفرع العائلي أو المدينة.

---

## ثالثاً: شجرة العائلة التفاعلية والأنساب

### 1. عرض الشجرة والتفاعل
- [ ] عرض الشجرة بشكل تفاعلي مرن يدعم التكبير، التحريك، والتصفح السلس بين الفروع.
- [ ] إمكانية تصفح الشجرة وفق خيارات متعددة:
	- [ ] شجرة كاملة (رجال ونساء).
	- [ ] شجرة رجال فقط.
	- [ ] شجرة نساء فقط.
	- [ ] إظهار الصور الشخصية للأفراد على عناصر الشجرة.
	- [ ] إمكانية رفع نسخة ورقية بصيغة PDF واستعراضها داخل التطبيق.

### 2. تمييز الحالات بالألوان
- [ ] 🟦 **الذكور الأحياء:** اللون الأزرق.
- [ ] 🟪 **الإناث الأحياء:** اللون البنفسجي.
- [ ] ⬛ **المتوفون (ذكور وإناث):** اللون الرمادي.

### 3. خدمة المصاهرة والربط الذكي
- [ ] إمكانية إضافة الأزواج والزوجات من خارج الأسرة.
- [ ] عند إضافة أم أو زوجة من داخل الأسرة، يتم اختيار الاسم مباشرة من قاعدة بيانات الأسرة لمنع تكرار البيانات.

### 4. أدوات النسب و القرابة
- [ ] **أداة الجد الجامع:** حساب و حصر "الجد الجامع" لمعرفة نقطة الالتقاء و صلة القرابة بين أي شخصين في الشجرة.
- [ ] **رمز الاستجابة السريعة (QR Code):** توفير باركود لكل ملف شخصي للتعرف السريع على صلة القرابة.
- [ ] **قسم نسب العائلة:** استعراض تاريخ العائلة العريق مع دعم تنسيقات النصوص الوثائقية والشهادات.

## رابعاً: الدليل والملف الشخصي

### 1. دليل الأسرة
- [ ] عرض جميع أفراد الأسرة في ==قائمة== هجائية مرتبة وقابلة للفلترة و البحث المتقدم.
- [ ] إمكانية الضغط على أي اسم للانتقال المباشر إلى ملفه الشخصي.

### 2. إدارة الملف الشخصي
- [ ] **البيانات الأساسية:** 
	- [ ] الاسم
	- [ ] الصورة الشخصية
	- [ ] تاريخ الميلاد
	- [ ] تاريخ الوفاة
	- [ ] الحالة الاجتماعية
	- [ ] الوظيفة
	- [ ] المؤهل التعليمي
	- [ ] وغيرها.
- [ ] **قنوات التواصل:**
	- [ ] ربط أرقام الجوال و حسابات التواصل الاجتماعي لفتحها مباشرة عبر تطبيقاتها دون الحاجة للنسخ و اللصق.
- [ ] **إعدادات الخصوصية:**
	- [ ] تحكم كامل للعضو في إظهار أو إخفاء بياناته الشخصية (أرقام التواصل، الصور) عن باقي المستخدمين.

## خامساً: الأخبار، الفعاليات، و التواصل

### 1. شاشة الأخبار و المناسبات
- [ ] نشر ==الأخبار== (مواليد، زواج، تعازي ومواقع العزاء، نجاحات وترقيات) مع إرفاق صور رئيسية للخبر.
- [ ] تخصيص صيغة ==أخبار== المواليد بذكر اسم الأب تلقائياً.
- [ ] ميزة المشاركة المباشرة للأخبار عبر منصات التواصل الاجتماعي (X، إنستغرام، وغيرها) (مثال: لما ارفع خبر مثلا علي ال.بسام يترفع علي منصات التواصل الاجتماعي).

### 2. التقويم العائلي و الفعاليات
- [ ] تقويم تفاعلي لمتابعة المناسبات و الفعاليات العائلية، مع تحديد المواقع و مقرات العزاء على الخريطة.
- [ ] أداة استطلاعات الرأي والتصويت لأخذ آراء أفراد العائلة في القرارات العامة.
- [ ] قسم تفاعلي للمسابقات، الفعاليات، والأنشطة العائلية.

### 3. قسم التواصل المباشر و طلب التعديلات
- [ ] تمكين الأعضاء من إرسال الأخبار، ==طلبات تعديل البيانات==، أو الإبلاغ عن الأعطال و المقترحات للإدارة.
- [ ] توفير قنوات تواصل تشمل: (واتساب، بريد إلكتروني، اتصال مباشر، SMS، و ==محادثة داخل التطبيق==) مع إمكانية إظهارها أو إخفائها بواسطة الإدارة.

### 1. دليل اللجان العائلية
- [ ] **هيكلة اللجان و تتضمن:**
	- [ ] لجنة التنمية الاجتماعية
	- [ ] لجنة إصلاح ذات البين
	- [ ] لجنة رعاية الشباب
	- [ ] لجنة الثقافة والإعلام
	- [ ] لجنة الوثائق
	- [ ] لجنة الاستثمار
	- [ ] لجنة الخدمات الإلكترونية
	- [ ] مجلس الأمناء
	- [ ] الإدارة التنفيذية
	- [ ] قسم مخصص لتشكيل اللجان النسائية (بالأسماء والمناصب).
	- [ ] صفحة خاصة لكل لجنة تحتوي على: (التعريف باللجنة، قائمة الأعضاء حتى 5 أعضاء مع مناصبهم، ووسائل التواصل المباشر معهم).
	- [ ] إمكانية رفع الطلبات و المراسلات مباشرة إلى اللجنة من صفحتها الخاصة.

### 2. الشخصيات و الأعلام
- [ ] إدراج الشخصيات البارزة، أدوارهم الفعالة، وإنجازاتهم، مع دعم رفع الصور والوثائق التاريخية المرتبطة بهم.

### 3. المكتبة الرقمية و الوسائط
- [ ] **أقسام المكتبة:**
	- [ ] ألبوم الصور
	- [ ] مكتبة ==الفيديو==
	- [ ] المنشورات والمخطوطات
	- [ ] مؤلفات و كتب أبناء الأسرة
	- [ ] الوثائق و الوصايا التاريخية
	- [ ] السماح للأعضاء برفع ومشاركة الصور والملفات لاعتمادها ونشرها من قبل الإدارة.

## سابعاً: خدمات التكافل، المالية، والخدمات الخاصة

### 1. إدارة المدفوعات والمالية
- [ ] ربط التطبيق ببوابات الدفع الإلكتروني المعتمدة (Mada, Visa, Apple Pay).
- [ ] عرض الحسابات البنكية الرسمية مصنفة حسب الغرض (اشتراكات، صدقات، زكاة) و توضيح المشرفين على كل حساب (==ادارة جديدة==).
- [ ] **حاسبة الزكاة الذكية:** لاحتساب زكاة الأموال، الذهب، والأسهم.
- [ ] **تحمّل رسوم العملية:** خيار اختياري يتيح للمتبرع إضافة رسوم بوابة الدفع الإلكتروني على مساهمته ليصل المبلغ صافياً للصندوق.
- [ ] لوحة لمتابعة سجل الاشتراكات والمساهمات المالية السابقة.

### 2. سوق العمل والاستشارات
- [ ] **الوظائف:** منصة لعرض الفرص الوظيفية المتاحة أو طلبات التوظيف والبحث عن عمل لأبناء الأسرة.
- [ ] **الاستشارات التخصصية:** طلب وتقديم استشارات متخصصة (طبية، قانونية، اقتصادية، وغيرها) من أصحاب الخبرة في العائلة.
- [ ] **جائزة المتفوقين:** قسم لإدارة المسابقات والمبادرات السنوية لتكريم المتميزين علمياً وحفظة القرآن الكريم.

### 3. قسم التقارير والإحصائيات
- [ ] لوحات بيانية وتقارير دورية تبرز أعمال العائلة، ==حجم الدعم المقدم==، و ==الإنجازات مدعومة بالأرقام، التواريخ==، والصور.

## ثامناً: التنبيهات والإعدادات الفنية

### 1. نظام الإشعارات والتنبيهات
- [ ] إرسال إشعارات فورية (Push Notifications & SMS) للأعضاء عند نشر الأخبار أو اقتراب موعد الفعاليات والمناسبات.
- [ ] إرسال إشعارات و تنبيهات بريدية فورية للمشرفين فور ورود أي طلب انضمام، تعديل، أو رسالة جديدة.

### 2. الأدوات الفنية والصفحات العامة
- [ ] صفحات مخصصة لـ: الشروط والأحكام، سياسة الخصوصية، ==واستعادة كلمة المرور عبر الرمز المؤقت== (OTP).
- [ ] أدوات تحكم وتخصيص ديناميكي لألوان وواجهات التطبيق من لوحة التحكم.

### 3. التكامل والربط البرمجي (Integrations)
- [ ] الربط مع مزود خدمات الرسائل النصية القصيرة (SMS Gateway).
- [ ] الربط مع تطبيق واتساب (WhatsApp Business API) وبوابات الدفع الإلكتروني.
- [ ] الربط مع خرائط جوجل (Google Maps API) لتحديد مواقع المناسبات والفعاليات بدقة.
