# Preconditions
- User has an active authenticated session.
- Dashboard login page URL is known.

# Steps
1. Log in and establish an active authenticated session.
2. Navigate to the dashboard login page.
3. Observe the system response.

# Expected Result
- The system redirects the user to the appropriate dashboard page.
- The user is not required to authenticate again.
