## Description

The application shall display products belonging to a selected category.

## Acceptance Criteria

-  Users can select a category from the Home screen.
    
-  The application retrieves category products from the Zid API.
    
-  Products belonging to the selected category are displayed.
    
-  Each product displays its name, image, and price.
    
-  The application displays a loading indicator while products are being retrieved.
    
-  The application displays an appropriate message when no products are available within the selected category.
    
-  An appropriate error message is displayed when category products cannot be retrieved.
    
-  Selecting a product navigates the user to the Product Details screen.
