## Description

The application shall allow users to navigate to the Product Details screen from a category product listing.

## Acceptance Criteria

-  Products displayed within a category are selectable.
    
-  Selecting a product navigates the user to the Product Details screen.
    
-  The Product Details screen displays information for the selected product.
