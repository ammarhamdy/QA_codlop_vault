## Description

The application shall allow users to view images associated with a product.

## Acceptance Criteria

-  Product images are displayed on the Product Details screen.
    
-  All images returned by the Zid API are available for viewing.
    
-  Users can navigate between multiple product images.
    
-  The application handles missing or unavailable images gracefully.
    
-  Product images are displayed using the highest available quality provided by the API.
