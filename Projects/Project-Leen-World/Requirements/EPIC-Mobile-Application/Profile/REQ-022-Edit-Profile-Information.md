## Description

The application shall allow users to update their personal profile information.

## Acceptance Criteria

-  Users can initiate profile editing from the Profile screen.
    
-  Users can modify editable profile fields.
    
-  Users can save profile changes.
    
-  Updated profile information is displayed after a successful save operation.
    
-  The application validates required fields before saving changes.
    
-  The application displays a success message after profile information is updated successfully.
    
-  The application displays an appropriate error message when profile updates fail.
