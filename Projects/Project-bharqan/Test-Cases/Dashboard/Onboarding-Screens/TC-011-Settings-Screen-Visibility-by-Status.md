# Preconditions
-Onboarding screen Exists.
# Steps
1. Set the settings screen status to **Active** and save.  
2. Open the application and navigate to the related screen.  
3. Verify the settings screen is displayed.
4. Change the same settings screen status to **Inactive** and save.  
5. Open the application again and navigate to the related screen.
# Expected Result
-When the status is **Active**, the settings screen is displayed in the application. When the status is **Inactive**, the settings screen is not displayed in the application.
