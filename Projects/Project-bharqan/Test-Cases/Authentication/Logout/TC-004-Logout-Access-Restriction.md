# Preconditions
User has logged out
# Steps
1. Click on **Logout** & Confirm logout 
2. Try to re-access the app without logging in again (e.g., reopen the app or navigate back).
# Expected Result
The user is redirected to the Login screen and cannot access the app after logout.
