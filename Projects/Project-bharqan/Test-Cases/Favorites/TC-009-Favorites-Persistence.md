# Preconditions
-User is logged in and has at least one product in the Favorites list.
# Steps
1. Open the **Favorites** page and verify the favorite product is displayed.  
2. Close the application completely.  
3. Reopen the application.  
4. Navigate to the **Favorites** page.
# Expected Result
-The previously added favorite product is still displayed in the Favorites list after reopening the application.
