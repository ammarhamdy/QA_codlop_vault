## Description
The App Builder shall allow the administrator to configure the title of the FAQ section using the `title` attribute.

## Acceptance Criteria
- [ ] The FAQ section contains a `title` attribute.
- [ ] The administrator can enter or modify the FAQ section title.
- [ ] The configured title is stored in the FAQ section configuration.
- [ ] The generated JSON contains the configured title in the `title` attribute.
- [ ] The Mobile App displays the configured title when section title display is enabled.
