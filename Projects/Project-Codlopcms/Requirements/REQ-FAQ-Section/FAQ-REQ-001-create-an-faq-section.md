## Description
The App Builder shall allow the administrator to create an FAQ section that can be configured and rendered on the mobile application's home screen.

## Acceptance Criteria
- [ ] The administrator can create an FAQ section.
- [ ] The created section is identified as an FAQ section.
- [ ] The section contains the required FAQ configuration structure.
- [ ] The created FAQ section can be saved successfully.
- [ ] The saved FAQ section can be provided to the mobile application for rendering.
