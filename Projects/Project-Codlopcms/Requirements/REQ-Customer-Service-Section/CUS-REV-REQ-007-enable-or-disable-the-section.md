## Description
The App Builder shall allow the administrator to control whether the Customer Review section is enabled or disabled using the `eye` icon.

## Acceptance Criteria
- [ ] The Customer Review section contains an `eye` icon.
- [ ] The administrator can enable the Customer Review section.
- [ ] When `enabled` is set to `true`, the Customer Review section is eligible for rendering in the Mobile App.
- [ ] The administrator can disable the Customer Review section.
- [ ] When `enabled` is set to `false`, the Customer Review section is not rendered in the Mobile App.
