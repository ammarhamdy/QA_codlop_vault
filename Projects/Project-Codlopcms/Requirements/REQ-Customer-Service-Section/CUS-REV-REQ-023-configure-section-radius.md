## Description
The App Builder shall allow the administrator to configure the corner radius of the Customer Review section using the `style.radius` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `style.radius` attribute.
- [ ] The administrator can configure the section corner radius.
- [ ] The configured radius value is stored in the section configuration.
- [ ] The generated JSON contains the configured value in `style.radius`.
- [ ] The Mobile App applies the configured radius to the Customer Review section.
- [ ] Changing the section radius does not modify other Customer Review section style properties.
