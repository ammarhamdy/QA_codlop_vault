## Description
The App Builder shall allow the administrator to configure the background color of the Customer Review section using the `style.background` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `style.background` attribute.
- [ ] The administrator can configure the Customer Review section background color.
- [ ] The configured background color is stored in the section configuration.
- [ ] The generated JSON contains the configured value in `style.background`.
- [ ] The Mobile App applies the configured background color when the section background is enabled.
- [ ] Changing the background color does not modify other Customer Review section style properties.
