## Description
The App Builder shall allow the administrator to create a Customer Review section that can be configured and rendered in the Mobile App.

## Acceptance Criteria
- [ ] The administrator can create a Customer Review section.
- [ ] The created section is identified as a Customer Review section.
- [ ] The section supports the Customer Review configuration structure.
- [ ] The Customer Review section can be saved successfully.
- [ ] The saved section can be included in the JSON configuration provided to the Mobile App.
- [ ] The Mobile App can render the created Customer Review section based on its configuration.
