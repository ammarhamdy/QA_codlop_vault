## Description
The mobile application shall fetch the Product Section JSON as part of the Home screen configuration retrieval.

## Acceptance Criteria
- [ ] JSON is fetched on Home screen load and on refresh.
- [ ] Fetch failures are handled without crashing the app (outside this feature's specific scope, per general network-error handling).
