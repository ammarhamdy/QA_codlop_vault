## Description
The Admin Panel shall allow the admin to select a `section_key` from a predefined, finite set of supported product section layouts: `grid_one`, `grid_two`, `grid_three`, `horizontal`.

## Acceptance Criteria
- [ ] Admin selects layout from a closed list of the four supported values.
- [ ] Layout selection is required to save/publish the section.
- [ ] Selecting a layout updates the corresponding `section_key` and `layout` values.
