## Description
The Admin Panel shall allow the admin to reorder selected products, and the resulting order shall be preserved in `data-strings`.

## Acceptance Criteria
- [ ] Admin can drag-and-drop or otherwise reorder selected products in the UI.
- [ ] The order of elements in `data-strings` reflects the admin-defined order.
- [ ] The mobile app renders products in the exact order provided in the array.
