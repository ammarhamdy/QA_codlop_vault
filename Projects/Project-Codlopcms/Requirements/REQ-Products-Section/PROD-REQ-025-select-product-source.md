## Description
The Admin Panel shall allow the admin to select a `productSource` (e.g., `selected_products`) specifying how the section's product list is determined.

## Acceptance Criteria
- [ ] Admin selects `productSource` from a closed list of supported values.
- [ ] `productSource` selection determines which additional configuration fields are shown (e.g., `data-strings` vs `parentCategoryId`).
