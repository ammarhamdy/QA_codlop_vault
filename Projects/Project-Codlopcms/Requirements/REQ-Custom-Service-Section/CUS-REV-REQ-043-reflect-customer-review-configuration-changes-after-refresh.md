## Description
The Mobile App shall reflect the latest valid Customer Review section configuration received from the App Builder after the mobile application's configuration is refreshed.

## Acceptance Criteria
- [ ] Changes to the Customer Review section title are reflected after refresh.
- [ ] Changes to the section enabled state are reflected after refresh.
- [ ] Changes to customer review ratings are reflected after refresh.
- [ ] Changes to customer names are reflected after refresh.
- [ ] Changes to review texts are reflected after refresh.
- [ ] Added customer review items are displayed after refresh.
- [ ] Removed customer review items are no longer displayed after refresh.
- [ ] Changes to the customer review order are reflected after refresh.
- [ ] Changes to Customer Review section styling are reflected after refresh.
- [ ] Changes to Customer Review item styling are reflected after refresh.
- [ ] Changes to section title visibility are reflected after refresh.
- [ ] The Mobile App uses the latest valid Customer Review configuration after refresh.
- [ ] Refreshing the configuration does not create duplicate customer review items.
