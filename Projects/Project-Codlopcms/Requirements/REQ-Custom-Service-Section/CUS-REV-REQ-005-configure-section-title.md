## Description
The App Builder shall allow the administrator to configure the title of the Customer Review section using the `title` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `title` attribute.
- [ ] The administrator can enter or modify the Customer Review section title.
- [ ] The configured title is stored in the Customer Review section configuration.
- [ ] The generated JSON contains the configured title in the `title` attribute.
- [ ] The Mobile App displays the configured title when section title display is enabled.
