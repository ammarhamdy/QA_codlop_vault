## Description
The App Builder shall allow the administrator to configure the Customer Review section title color using the `style.titleColor` attribute.

## Acceptance Criteria
- [ ] The Customer Review section contains a `style.titleColor` attribute.
- [ ] The administrator can configure the section title color.
- [ ] The configured title color is stored in the section configuration.
- [ ] The generated JSON contains the configured value in `style.titleColor`.
- [ ] The Mobile App applies the configured title color to the section title when the title is displayed.
- [ ] Changing the title color does not modify other Customer Review section style properties.
