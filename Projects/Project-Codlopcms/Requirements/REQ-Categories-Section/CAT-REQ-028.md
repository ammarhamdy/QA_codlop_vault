## Description

The Admin Panel shall enforce a minimum number of selected categories before the section can be enabled/published.

## Acceptance Criteria
- [ ] Admin cannot enable a section with zero selected categories (exact minimum threshold to be confirmed — see Open Questions).
- [ ] A validation message is displayed when the minimum is not met.
