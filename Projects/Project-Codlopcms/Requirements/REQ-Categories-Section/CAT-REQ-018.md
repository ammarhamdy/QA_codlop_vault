## Description

The Admin Panel shall allow the admin to define the `ctaText` label (e.g., "تسوق الآن") displayed on the section's call-to-action element.

## Acceptance Criteria
- [ ] Admin can enter free text, including RTL/UTF-8 characters, for `ctaText`.
- [ ] `ctaText` is only rendered when `showCta` is true.
