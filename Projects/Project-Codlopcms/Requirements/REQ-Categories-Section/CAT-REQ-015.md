## Description

The Admin Panel shall allow configuration of `priceColor`, `highlightBadgeTextColor`, and `highlightBadgeBackgroundColor`, used respectively when prices and highlight badges are shown on category items.

## Acceptance Criteria
- [ ] Fields accept valid hex color values.
- [ ] `priceColor` is only applied when `showPrice` is true.
- [ ] Highlight badge colors are only applied when `highlight` is not `none`.
