## Description

Disabling a section shall not delete its configuration; the admin shall be able to re-enable it later with the previously configured style, settings, and category selection intact.

## Acceptance Criteria
- [ ] Disabling a section preserves all `style`, `settings`, and category selection data.
- [ ] Re-enabling the section restores the prior configuration without requiring re-entry.
