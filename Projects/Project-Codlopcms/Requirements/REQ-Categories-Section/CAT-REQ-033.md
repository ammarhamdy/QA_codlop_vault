## Description

The Admin Panel shall allow the admin to toggle the section's `enabled` flag to control whether the section is shown on the mobile Home screen.

## Acceptance Criteria
- [ ] `enabled` accepts boolean true/false.
- [ ] When `enabled` is false, the section is excluded from rendering on the mobile Home screen.
