## Description

The Admin Panel shall allow the admin to toggle `showBannerTextCta` to control display of a banner-style text CTA element within the section, independent of the primary CTA.

## Acceptance Criteria
- [ ] `showBannerTextCta` accepts boolean true/false.
- [ ] Behavior is documented as distinct from `showCta`/`ctaText` (see CAT-REQ-018, CAT-REQ-019) pending confirmation (see Open Questions).
