## Description

The mobile application shall apply the `style` and `settings` values from the JSON to the rendered section and its category items.

## Acceptance Criteria
- [ ] All style fields listed in Section 3 are applied to the corresponding visual elements.
- [ ] All settings fields listed in Section 3 are applied to the corresponding behavior/visibility of elements.
