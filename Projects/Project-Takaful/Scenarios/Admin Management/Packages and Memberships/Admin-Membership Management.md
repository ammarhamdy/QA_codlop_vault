# إنشاء مستوي عضوية

# الفلو:

1. المشرف يدخل على **إدارة العضويات**.  
2. يضغط على **إضافة عضوية**.  
3. يدخل بيانات العضوية: 
- اسم العضوية.
- شروط الترقية.
- شروط التخفيض.
- نسبه الخصم عند التجديد.
4. يحفظ بيانات العضوية.  
5. يتم إنشاء العضوية بنجاح.

# القواعد:

- العضوية تُمنح للعميل فقط عند الاشتراك في **باقة مدفوعة**.
- يبدأ العميل عند الاشتراك بمستوى **Classic**.

---
# تعديل مستوي العضوية

# الفلو:

1. المشرف يدخل على **إدارة العضويات**.  
2. يختار العضوية المراد تعديلها.  
3. يعدل بيانات العضوية.  
4. يحفظ التعديلات.  
5. يتم تحديث بيانات العضوية بنجاح.

# القواعد:

- تعديل بيانات العضوية، مثل **شروط الترقية أو شروط التخفيض أو نسبة الخصم عند التجديد**، يطبق على **الاشتراكات الجديدة فقط**.
- العملاء المشتركين مسبقًا يحتفظون ببيانات وشروط العضوية التي كانت مطبقة عليهم وقت اشتراكهم.

---
# حذف مستوي العضوية

# الفلو:

1. المشرف يدخل على **إدارة العضويات**.  
2. يحدد العضوية المراد حذفها.  
3. يحذف العضوية.  
4. يتم حذف العضوية بنجاح.

# القواعد:

- لا يمكن تجديد الاشتراك على نفس مستوي العضوية المحذوفة.
- العملاء الحاليون على العضوية المحذوفة يظلون على نفس المستوى ويستفيدون من مزاياها **حتى انتهاء مدة عضويتهم الحالية**.
- ==عند تجديد الاشتراك، يعيّن النظام للعميل **مستوى متاح تلقائيًا** وفقًا لقواعد تحديد المستوى المتفق عليها.==
