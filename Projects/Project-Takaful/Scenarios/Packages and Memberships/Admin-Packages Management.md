# إنشاء باقة

# الفلو:

1. المشرف يدخل على **إدارة الباقات**.  
2. يضغط على **إنشاء باقة**.  
3. يدخل بيانات الباقة:
- اسم الباقة.
- الوصف.
- المزايا.
- شروط التجديد.
- عدد الأشخاص.
- السعر.
- الفترة.
4. يحفظ الباقة.  
5. يتم إنشاء الباقة بنجاح.

# القواعد:

- تفاصيل الباقة وشروطها وصلاحيتها وسعرها تظهر للعملاء.
- لا يستفيد العميل من مزايا الباقة إلا بعد الاشتراك فيها.

---

# تعديل باقة

# الفلو:

1. المشرف يدخل على **إدارة الباقات**.  
2. يختار الباقة المطلوب تعديلها.  
3. يضغط على **تعديل**.  
4. يعدل بيانات الباقة المطلوبة.  
5. يحفظ التعديلات.  
6. يتم تحديث بيانات الباقة بنجاح.

# القواعد:

- أي تعديل على **السعر أو عدد الأشخاص في الباقة العائلية أو الفترة** يطبق على الاشتراكات الجديدة فقط.
- يحتفظ العملاء المشتركين مسبقًا ببيانات وشروط اشتراكهم وقت الاشتراك.

---

# حذف باقة

# الفلو:

1. المشرف يدخل على **إدارة الباقات**.  
2. يختار الباقة المطلوب حذفها. 
3. يضغط على **حذف**.
4.  يتم حذف الباقة بنجاح.
  
# القواعد:

- حذف الباقة يمنع الاشتراكات الجديدة ولا يؤثر على الاشتراكات الحالية.

---

# تفعيل / تعطيل باقة

# **الفلو :**
1. المشرف يدخل على إدارة الباقات.  
2. يختار الباقة المطلوبة.  
3. يضغط على **تفعيل** أو **تعطيل**.  
4. يتم تحديث حالة الباقة بنجاح.

# القواعد: 

- الباقة المعطلة لا تظهر للعملاء.
