## Source Notes

- لم يتم تحديد آلية ترتيب المراكز حسب المسافة.
    
- لم يتم تحديد وحدة قياس المسافة.
    
- لم يتم تحديد مصدر بيانات الخرائط أو الاتجاهات.
    
- لم يتم تحديد تعريف حالات المركز.
    
- لم يتم تحديد الفلاتر المتاحة تحديدًا داخل شاشة «الأقرب».
