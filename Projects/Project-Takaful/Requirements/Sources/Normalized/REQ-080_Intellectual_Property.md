## Source Notes

- نقل الملكية مرتبط بشروط السداد في العقد.
    
- لم يتم تحديد معالجة المكونات أو المكتبات أو الأدوات المملوكة مسبقًا للمزود.
    
- لم يتم تحديد تراخيص Open Source المستخدمة في المشروع.
    
- لم يتم تحديد حدود «المكونات الخاصة» قانونيًا أو تقنيًا.
