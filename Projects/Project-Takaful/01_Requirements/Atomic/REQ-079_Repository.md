## Normalized Requirements

### RQ-0965

### RQ-0966

**Requirement:**

> يفضل أن يكون مستودع Git باسم العميل.

**Source:** Section 78 — Repository

---

### RQ-0967

**Requirement:**

> إذا لم يكن المستودع باسم العميل، يجب أن يحصل العميل على Owner/Admin Access من بداية المشروع.

**Source:** Section 78 — Repository

---

### RQ-0968

**Requirement:**

> يجب أن يحتفظ المستودع بتاريخ التطوير الفعلي للمشروع.

**Source:** Section 78 — Repository

## Source Notes

- استخدام «يفضل» في اسم المستودع يجعل RQ-0966 تفضيلًا وليس شرطًا إلزاميًا بنفس قوة المتطلبات الأخرى.
    
- لم يتم تحديد Branching Strategy.
    
- لم يتم تحديد Pull Request Policy.
    
- لم يتم تحديد Code Review requirements.
    
- لم يتم تحديد Backup أو حماية المستودع.
