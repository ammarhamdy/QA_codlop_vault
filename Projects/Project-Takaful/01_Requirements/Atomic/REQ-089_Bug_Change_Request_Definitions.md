# Requirement Group: Bug vs Missing Requirement vs Change Request

## Source Reference

**Document:** Takaful_Client_Requirements_Original_v1.0

**Original Section:** 88

**Original Title:** الفرق بين التعديل والخلل

---

## Definitions

### RQ-1045 — Bug

**Definition:**

> Bug هو أي شيء لا يعمل حسب المواصفة المعتمدة.

**Source:** Section 88 — الفرق بين التعديل والخلل

---

### RQ-1046 — Missing Requirement

**Definition:**

> Missing Requirement هي وظيفة موجودة في الملحق ولم يتم تنفيذها.

**Source:** Section 88 — الفرق بين التعديل والخلل

---

### RQ-1047 — Change Request

**Definition:**

> Change Request هي وظيفة جديدة يطلبها العميل ولم تكن ضمن العقد أو الملحق أو التصاميم المعتمدة.

**Source:** Section 88 — الفرق بين التعديل والخلل

---

### RQ-1048

**Requirement:**

> لا يعتبر الـBug تعديلًا مدفوعًا.

**Source:** Section 88 — الفرق بين التعديل والخلل

---

### RQ-1049

**Requirement:**

> لا يعتبر Missing Requirement تعديلًا مدفوعًا.

**Source:** Section 88 — الفرق بين التعديل والخلل
