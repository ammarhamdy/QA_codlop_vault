# Preconditions
-Admin is logged in and on the **Change Password** page.
# Steps
1. Enter the current password.  
2. Enter the same value in the **New Password** field &**Confirm Password** field.  
3. Click **Save**.
# Expected Result
-The system displays a validation message indicating that the new password must be different from the current password, and the password is not updated.
