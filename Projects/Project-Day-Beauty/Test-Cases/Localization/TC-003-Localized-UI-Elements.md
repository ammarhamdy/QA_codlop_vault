# Preconditions
-User install application.
# Steps
1. Navigate through all available screens.  
2. Verify screen titles, buttons, labels, placeholders, navigation menus, tab names, dialog titles, dialog messages, dialog buttons, loading messages, validation messages, success messages, error messages, and empty-state messages.  
3. Repeat the verification after switching to the other supported language.
# Expected Result
-All UI elements are displayed in the selected language. No untranslated, mixed-language, or missing text is displayed. All dialogs, messages, buttons, menus, tabs, placeholders, labels, and screen titles are correctly localized.
