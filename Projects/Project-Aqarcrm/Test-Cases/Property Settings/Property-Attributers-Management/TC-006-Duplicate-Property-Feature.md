# Preconditions
- Attribute with the same name already exists for the selected property type.
# Steps
1. Click **Add Property Attributes**.  
2. Select the same property type.  
3. Enter the existing Attributes name.  
4. Click **Save**.
# Expected Result
-The system prevents creating a duplicate Attributes for the same property type and displays an appropriate error message.
