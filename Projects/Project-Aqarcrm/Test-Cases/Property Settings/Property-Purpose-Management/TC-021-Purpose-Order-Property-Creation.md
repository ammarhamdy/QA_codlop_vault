# Preconditions
-At least two active property purposes exist and their display order has been changed.
# Steps
1. Navigate to **Property Settings → Property Purposes**.  
2. Change the order of the property purposes.  
3. Navigate to Properties & click add property.  
4. Open the **Property Purpose** dropdown & Review the order of the available purposes.
# Expected Result
-The active property purposes are displayed in the **same order configured in Property Settings**.
