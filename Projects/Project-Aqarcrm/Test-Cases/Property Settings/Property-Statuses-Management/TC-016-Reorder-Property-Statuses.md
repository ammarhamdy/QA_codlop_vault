# Preconditions
-At least two property statuses exist.
# Steps
1. Navigate to **Property Settings & move to Property Statuses**.  
2. Change the order of the property statuses using the available reorder option.  
3. Refresh the page.
# Expected Result
-The property statuses are displayed according to the newly configured order, and the updated order is preserved after refreshing or reopening the page.
