# Preconditions
-A supervisor exists.
# Steps
1. Change the supervisor status from **Inactive** to **Active**.   
2. Change the supervisor status from **Active** to **Inactive**.  
3. Verify the status is updated.
# Expected Result
-The supervisor status is updated successfully when activated or deactivated, and the new status is reflected correctly in the supervisors list.
