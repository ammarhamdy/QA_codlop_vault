# Preconditions
-User is on the Home page.
# Steps
1. Select any property purpose tab (e.g., **Sale**).  
2. Select any search filter.  
3. Verify the selected tab is still active.  
4. Click another property purpose tab (e.g., **Rent**).
# Expected Result
-The initially selected property purpose remains active while interacting with the search filters. Once another property purpose tab is selected, the previous tab is deselected, and the newly selected tab becomes active.
