# Preconditions
-User is on the Home page, and the category slider contains multiple categories.
# Steps
1. Navigate to the last category using the **Next** button.  
2. Click **Next** again.   
3. Navigate to the first category using the **Previous** button.  
4. Click **Previous** again.  
5. Verify the behavior.
# Expected Result
-Clicking **Next** on the last category and **Previous** on the first category does not perform any navigation. The slider remains on the current category without any errors or unexpected behavior.
