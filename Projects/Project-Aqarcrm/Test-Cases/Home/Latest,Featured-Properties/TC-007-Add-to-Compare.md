# Preconditions
-The user is on the Home page& the Latest Properties section contains at least one property.
# Steps
1. Navigate to the **Latest Properties** section.  
2. Click the **Compare** icon on any property.
3. Click again.
# Expected Result
-The selected property is successfully added to the comparison list on first click, and removed from compare list on second click & the Compare icon/state is updated accordingly.
