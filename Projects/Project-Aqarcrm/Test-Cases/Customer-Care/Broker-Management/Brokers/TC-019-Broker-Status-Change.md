# Preconditions
-A broker exists.
# Steps
1. Navigate to the Brokers page.  
2. Change the Brokers status from **Active** to **Inactive** and verify the result.  
3. Change the Broker's status from **Inactive** to **Active** and verify the result.
# Expected Result
-The broker status is updated successfully according to the selected action, and the change is reflected correctly in the broker list and statistics.
