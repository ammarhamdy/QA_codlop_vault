# ملف الدور: العميل

## 1. نظرة سريعة

العميل، شخص مسجّل في المنصة برقم جواله ويدخل برمز تحقق.

يتصفح كل ما يتصفحه الزائر من الرئيسية و البحث و صفحة الشاليه و التقويم و التقييمات و صفحات المحتوى، و يزيد عليه إظهار وسيلة التواصل مع المالك و طلب المعاينة و الحجز و الدفع و الحفظ في المفضلة و التقييم و الإبلاغ و فتح النزاعات.
و يدير حسابه بنفسه من التطبيق: تسجيل وتسجيل دخول و خروج و عرض الملف الشخصي و تعديله، و حذف الحساب و استعادته.
و إذا جدول حذف حسابه فلا يستطيع الحجز أو الدفع أو فتح نزاع حتى يستعيده.
و يساند هذا الدور نظامان:
+ المجدول الذي ينفّذ الحذف بعد 30 يومًا، ومزوّد الرسائل النصية الذي يرسل رمز التحقق ورسالة «`حُذف حسابك`».

## 2. بيانات العميل

| الحقل               | النوع                     | إلزامي | القواعد                                                                                     |
| ------------------- | ------------------------- | ------ | ------------------------------------------------------------------------------------------- |
| رقم الجوال          | رقم                       | نعم    | معرّف الدخول؛ فريد بين الحسابات غير المحذوفة                                                |
| الاسم               | نص                        | نعم    | يصبح «`مستخدم محذوف`» بعد الحذف                                                             |
| رقم الهوية الوطنية  | نص (10 أرقام)             | نعم    | يبدأ بـ 1 ويجتاز خوارزمية التحقق؛<br>فريد بين الحسابات غير المحذوفة؛<br>يُحتفظ به بعد الحذف |
| اسم النشاط          | نص                        | لا     | يُحتفظ به بعد الحذف                                                                         |
| صورة الهوية         | صورة                      | نعم    | ==تُحذف== عند تنفيذ الحذف                                                                   |
| حالة الحساب         | نشط / مجدول للحذف / محذوف | نعم    | الحذف soft-delete                                                                           |
| تاريخ الحذف المجدول | تاريخ ووقت                | لا     | يُملأ فقط عند «`مجدول للحذف`»                                                               |

## 3. الوظائف

### أ. إدارة الحساب

| الوظيفة            | الحقول المستخدمة                               | القاعدة                                                                   |
| ------------------ | ---------------------------------------------- | ------------------------------------------------------------------------- |
| تسجيل الدخول       | الجوال                                         | رمز تحقق؛ إن كان الحساب «`مجدولًا للحذف`» تظهر رسالة الاستعادة            |
| تسجيل البينات      | الجوال، الاسم، الهوية، صورة الهوية، اسم النشاط | التحقق من الهوية؛ رمز تحقق؛ يمكن التسجيل برقم حساب محذوف كحساب جديد       |
| تسجيل الخروج       | لا يوجد                                        | تسجيل الدخول                                                              |
| عرض الملف الشخصي   | كل الحقول                                      | تسجيل الدخول                                                              |
| تعديل الملف الشخصي | الاسم، اسم النشاط، صورة الهوية، الجوال         | تسجيل الدخول؛ تغيير الجوال برمز للرقم الجديد؛ الهوية لا تُعدَّل من العميل |

### ب. حذف الحساب واستعادته (باستخدام التطبيق)

| الوظيفة        | الفاعل  | القاعدة                                                                                                                                                                                                                          |
| -------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| طلب حذف الحساب | العميل  | 1) عرض ما يُحذف وما يُحتفظ به.<br>2) فحص الموانع. [[#**موانع الحذف**]]<br>3) رمز تحقق.<br>4) تأكيد بحوار أحمر.<br>5) جدولة الحذف بعد 30 يومًا وتحويل الحالة إلى «`مجدول للحذف`».<br>6) إشعار داخلي بتاريخ الحذف وطريقة الاستعادة |
| استعادة الحساب | العميل  | عند الدخول خلال 30 يومًا: «`حسابك مجدول للحذف في {التاريخ}. هل تريد استعادته؟`»، وبعد الموافقة تعود الحالة «`نشط`»                                                                                                               |
| تنفيذ الحذف    | المجدول | بعد انتهاء المهلة، حسب جدول الأثر أدناه                                                                                                                                                                                          |

#### **موانع الحذف:**

| المانع       | الرسالة                                                                      |
| ------------ | ---------------------------------------------------------------------------- |
| طلب دفع معلق | «`لا يمكن حذف الحساب وطلب الدفع PAY-… قيد المراجعة. ألغه أو انتظر القرار`»   |
| حجز قائم     | «`لا يمكن حذف الحساب ولديك حجز قائم. ألغه أو انتظر انتهاءه`»                 |
| نزاع مفتوح   | «`لا يمكن حذف الحساب ولديك نزاع مفتوح. انتظر إغلاقه`» (==صياغة مقترحة مني==) |

#### **أثر تنفيذ الحذف:**

| العنصر                                    | بعد التنفيذ               |
| ----------------------------------------- | ------------------------- |
| الاسم                                     | «`مستخدم محذوف`»          |
| رقم الجوال                                | بصمة غير قابلة للاسترجاع  |
| صورة الهوية                               | تُحذف                     |
| الهوية الوطنية، اسم النشاط، باقي البيانات | تبقى (soft-delete)        |
| التقييمات                                 | تبقى بلا اسم              |
| الإشعار                                   | رسالة نصية «`حُذف حسابك`» |
| التسجيل بنفس الرقم                        | مسموح كحساب جديد          |

### ج. وظائف الخدمة

| الوظيفة          | الحقول المستخدمة    | القاعدة                          |
| ---------------- | ------------------- | -------------------------------- |
| إظهار التواصل    | الجوال              | تسجيل الدخول                     |
| طلب معاينة       | الاسم، الجوال       | تسجيل الدخول                     |
| حجز شاليه        | الهوية، صورة الهوية | تسجيل الدخول + حالة الحساب «نشط» |
| الحفظ في المفضلة | لا يوجد             | تسجيل الدخول                     |
| تقييم            | الاسم               | تسجيل الدخول                     |
| إبلاغ            | لا يوجد             | تسجيل الدخول                     |
| فتح نزاع         | لا يوجد             | مرتبط بحجز + حالة الحساب «نشط»   |
| دفع الحجز        | لا يوجد             | تسجيل الدخول + حالة الحساب «نشط» |

**قيد الحساب المجدول للحذف:** لا يستطيع الحجز ولا الدفع ولا فتح نزاع حتى يستعيد حسابه.
رسالة مقترحة مني:
+ «`حسابك مجدول للحذف. استعد حسابك لتتمكن من المتابعة`». بقية الوظائف متاحة.

## 4. حماية رمز التحقق (قيم مقترحة مني، عدّلها)

|البند|القيمة|
|---|---|
|صلاحية الرمز|5 دقائق|
|المحاولات الخاطئة|5، ثم يُبطل الرمز|
|إعادة الإرسال|بعد 60 ثانية، وبحد أقصى 5 طلبات في الساعة لكل رقم|

## 5. القرارات المعتمدة
- الحذف والاستعادة من التطبيق فقط، ولا توجد صفحة ويب.
- رقم الهوية يُحتفظ به بلا مدة، ومقبول أن تتيح البصمة ربط الحساب الجديد بالقديم.
- يُنصح بمراجعة نظام حماية البيانات الشخصية (PDPL) قبل الاعتماد النهائي لقرار الاحتفاظ.

## 6. نقاط ناقصة في المتطلبات
1. **دفع الحجز وإلغاء الحجز:** كلاهما مذكور في رسائل الموانع («ألغه»)، لكن لا توجد لهما تفاصيل بعد.
2. **تفرّد الهوية:** افترضتُ أنه على الحسابات غير المحذوفة فقط، حتى يُسمح بالتسجيل الجديد بنفس الهوية.
