# الرئيسية
+ شريط بحث (المدينة، التواريخ، الضيوف).
+ البنرات الموجهة لجمهوره داخل نافذتها الزمنية.
+ قسم «المميزة» حتى 10 إعلانات مع «عرض الكل».
+ قسم أنواع الأماكن اذا وجد انواع للاماكن.
 
### قواعد عامة للرئيسية
+ لا بنرات أو لا مميزة: يختفي القسم كاملًا.
+ **قسم أنواع الأماكن لا يظهر** ما دام نوع واحد «شاليه» مفعّلًا.
+ لا إعلانات منشورة بعد: «نجهز لك أماكن مميزة قريبًا» + «تواصل معنا إن كنت مؤجّرًا».
+ سحب للتحديث.
+ ==البنر يظهر فقط داخل نافذته ولجمهوره (الكل، الزوار، العملاء، المؤجرون)، والمرتبط بشاليه أصبح غير متاح يختفي آليًا.==
