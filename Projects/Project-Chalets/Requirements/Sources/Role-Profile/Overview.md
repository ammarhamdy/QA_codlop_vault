# المستخدمون

1. **الزائر:** بلا دخول؛ يتصفح الرئيسية والبحث وصفحة الشاليه والتقويم والتقييمات وصفحات المحتوى.

2. **العميل:** سجّل برقم جواله؛ يُظهر التواصل، ويطلب معاينة، ويحجز، ويحفظ في المفضلة، ويقيّم، ويبلّغ، ويفتح نزاعًا.

3. **المؤجّر الفرد:** عميل سعودي قُبل بالهوية الوطنية.

4. **المؤجّر الشركة:** المسؤول أو المفوّض عن شركة بسجل تجاري؛ الطريق الوحيد لغير السعودي. لا حسابات فرعية لموظفي الشركة.

5. **فريق الإدارة:** موظف المراجعة، المعاين، موظف المالية، موظف الدعم والبلاغات، مسؤول المحتوى والتسويق، مدير النظام، والمدير العام (حساب المالك المحمي).

6. **النظام:** مهام مجدولة تنهي المهل، وترسل التذكيرات، وتحرر الحجوزات المؤقتة، وتنفذ الحذف بعد المهل.
