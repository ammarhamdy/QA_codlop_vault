# قواعد عامة

**تطبيق جوال واحد** على iOS وAndroid للعميل والمؤجّر معًا؛ بعد قبول المستخدم مؤجّرًا يظهر مبدّل «وضع العميل / وضع المؤجّر».

**اللغة و المنطقة:**
العربية وحدها مفعّلة عند الإطلاق، و المنصة متعددة اللغات من أول جدول؛ إضافة لغة لا تحتاج تغيير الكود.

**التقويم:**
التقويم **ميلادي فقط** في كل الواجهات والمستندات، ولا عرض للهجري.

**طريقة عرض الأرقام:**
الأرقام تُعرض لاتينية افتراضيًا، والإدخال يقبل العربية واللاتينية.

**طريقة عرض الاوقات الأوقات:**
كل الأوقات بتوقيت الرياض، والعملة الريال فقط، والأسعار تُكتب «1,250 ر.س».

**كود الدولة:**
أرقام الجوال ‎`+966` فقط افتراضيًا، والإدارة تفعّل دولًا أخرى.

**المدن و المناطق و الاحياء:**
**القصيم أولًا:** المدن مُعدّة عند الإطلاق بمحافظات القصيم، والإدارة تضيف المدن والأحياء دون تطوير.

# العميل

## شريط التنقل
 الرئيسية، البحث، المفضلة، الإشعارات، حسابي.

## الرئيسية
+ شريط بحث (المدينة، التواريخ، الضيوف).
+ البنرات الموجهة لجمهوره داخل نافذتها الزمنية.
+ قسم «المميزة» حتى 10 إعلانات مع «عرض الكل».
+ قسم أنواع الأماكن اذا وجد انواع للاماكن.
 
### قواعد عامة للرئيسية
+ لا بنرات أو لا مميزة: يختفي القسم كاملًا.
+ **قسم أنواع الأماكن لا يظهر** ما دام نوع واحد «شاليه» مفعّلًا.
+ لا إعلانات منشورة بعد: «نجهز لك أماكن مميزة قريبًا» + «تواصل معنا إن كنت مؤجّرًا».
+ سحب للتحديث.
+ ==البنر يظهر فقط داخل نافذته ولجمهوره (الكل، الزوار، العملاء، المؤجرون)، والمرتبط بشاليه أصبح غير متاح يختفي آليًا.==

## البحث
+ يضغط شريط البحث: يختار المدينة والحي، ثم التواريخ من المنتقي الميلادي، ثم عدد الضيوف.

### شكل نتائج البحث
النتائج بطاقات؛ كل بطاقة:
+ الصورة الرئيسية.
+ الاسم.
+ المدينة والحي.
+ السعة.
+ متوسط التقييم وعدده أو «جديد».
+ شارة «معاين».
+ شارة «مميز». إن وُجدت.
+ زر المفضلة.
+ السعر:
   - مع تواريخ: المجموع المحسوب لها، مثل «1,900 ر.س لليلتين».
   - بلا تواريخ: «من {أقل سعر} ر.س».

### قواعد البحث
- 20 نتيجة للصفحة, المزيد يُحمّل بالتمرير؛ فشل تحميل المزيد: «تعذر تحميل المزيد» مع إعادة المحاولة دون فقد ما ظهر.

## الفلاتر
+ المدينة.
+ الحي.
+ ==🔴التواريخ==.
+ الضيوف.
+ السعر من/إلى.
+ الغرف (≥).
+ المرافق (كل المختارة).
+ التقييم (≥).
+ مع عداد للفلاتر المفعّلة و «مسح الكل».
+ **فلتر النوع لا يظهر** ما دام نوع واحد مفعّلًا.

### قواعد الفلاتر 
+ لا نتائج: «لا توجد أماكن مطابقة. جرّب تغيير التواريخ أو إزالة بعض الفلاتر» + `مسح الفلاتر` `تغيير التواريخ`.
+ المنتقي يمنع: تاريخ الخروج قبل تاريخ  الدخول، والتاريخ الماضي،
+ أقصى مدة للبحث 30 ليلة.

## قواعد البحث و الفلاتر
+ الترتيب الافتراضي: الأحدث، السعر، التقييم
+ مع التواريخ لا يظهر إلا الشاليه المتاح طوال المدة كلها (الوحدة متاحة إذا: حالتها «متاح»).
+ المميزة أولًا داخل النتائج المطابقة فقط.
+ ==الإعلان يظهر للعامة فقط وهو «منشور» مع حساب مؤجّر نشط واشتراك ساري؛ التحديث يظهر للعامة خلال 5 دقائق.==
+ المدن والأحياء والمرافق المعطّلة لا تظهر في الفلاتر.

## صفحة الشالية
- تعرض:
	- الصور (معرض بملء الشاشة وتكبير).
	+ الاسم.
	+ المواصفات.
	+ المرافق.
	+ نظام الإيجار و أوقات الدخول و الخروج.
	+ الشروط.
	+ التأمين:
		+ «التأمين: 500 ر.س — يُدفع ويُرد في المكان» مع النص الثابت «يُدفع التأمين ويُرد في المكان بين العميل والمؤجّر، ولا يُدفع عبر المنصة»؛ أو «لا يوجد تأمين»
	+ سياسة الإلغاء المختارة.
	+ التقويم بالأسعار.
	+ التقييم:
		+ أول 3 تقييمات مع ردود المؤجّر و «عرض كل التقييمات».
		+ بلا تقييمات: «جديد — لا تقييمات بعد».
	+ رقم التصريح السياحي يظهر فقط إن فعّلته الإدارة للعامة.
	+ شارة «معاين» وتاريخ آخر معاينة معتمدة.
	+ «آخر تحديث للتقويم: منذ {مدة}».
	+ الموقع:
		+ دائرة تقريبية فقط للعامة؛ الدبوس الدقيق.
		+ «افتح في الخرائط» بعد إظهار التواصل فقط.
	+ زر «حجز».
	+ زر «إظهار بيانات التواصل» (أساسي).
	+ زر «طلب معاينة» (ثانوي).
	+ زر القلب ♥️ للمفضلة.
	+ زر «مشاركة».
	+ زر «إبلاغ» من قائمة.
	+ شريط «إدارة الإعلان» بدل أزرار العميل (==اذا فتح الصفحة المؤجّر صاحب الإعلان==).
	+ المشاهدات:
		+ تُحتسب مشاهدة الصفحة مرة لكل جهاز لكل إعلان لكل يوم لقياس التحويل، ولا تُعرض للعامة.

### الافصاح
- **حد يومي للعميل: 30 إظهار تواصل أو طلب معاينة لإعلانات مختلفة** (حماية للأرقام من الجمع).
- تكرار نفس العميل على نفس الإعلان بنفس النوع خلال 24 ساعة لا ينشئ سجلًا جديدًا ==🔴ولا إشعارًا
- عند الضغط علي طلب معاينة او اظهار بينات التواصل اظهر bottom sheet للتكيد ان بينات العميل ستظهر للمؤجر (الافصاح), لاتمام عملية التواصول او طلب المعاينة.
- الافصاح يظهر اول مرة فقط لطب االمعاينة او اظهار بينتا التواصول.
- لا يُسجل مهتم للمؤجّر على إعلانه، واسم العميل ورقمه يصلان للمؤجّر **بعد الإفصاح فقط**.
- ==المؤجّر على إعلانه برابط قديم: «هذا إعلانك» ولا يُسجل مهتم.==

### حالات يتم ارسال فيها اشعار للمؤجر:
- طلب المعاينة.

### حالات الشالية
- الإعلان معطّل أو موقوف أو انتهى اشتراك مؤجّره: «هذا المكان غير متاح حاليًا» بالصورة والاسم فقط و «تصفح أماكن مشابهة»، بلا أزرار تواصل.
- غير موجود أو مسودة: «لم نجد هذه الصفحة» + «تصفح الأماكن».


### قواعد صفحة الشالية
- يغيّر التواريخ فيُحسب المجموع، مثل: «ليلتان: الخميس 900، الجمعة 1000 — المجموع 1,900 ر.س».
- **زر «حجز» يظهر فقط إذا:** الإعلان منشور، واشتراك المؤجّر ساري، وللشاليه حساب بنكي معروض، والمستخدم ليس صاحب الإعلان.


### سياسة الإلغاء المعروضة ملزمة للمؤجّر
**سياسة الإلغاء المعروضة ملزمة للمؤجّر** بموجب شروطه رغم أن المال خارج المنصة. السياسات الثلاث المعتمدة:

| السياسة | المستحق للعميل عند إلغائه |
|---|---|
| مرنة | 100% حتى 24 ساعة قبل الدخول، ثم 0% |
| متوسطة | 100% حتى 3 أيام قبل الدخول، و50% من 3 أيام حتى 24 ساعة، و0% في آخر 24 ساعة |
| صارمة | 100% حتى 7 أيام قبل الدخول، و50% من 7 أيام حتى 48 ساعة، و0% في آخر 48 ساعة |



## تسجيل الدخول و حالاتة
- «إعادة الإرسال» تظهر بعد 60 ثانية.
- الاسم (2–60 حرفًا).
- رمز خاطئ: «الرمز غير صحيح. متبقٍ {n} محاولات»؛ منتهٍ: «انتهت صلاحية الرمز، اطلب رمزًا جديدًا»؛ مقفل: «أوقفنا المحاولة 15 دقيقة لحماية حسابك».
- حساب موقوف: «حسابك موقوف: {السبب}» وزرا «اعتراض» و«تواصل معنا» فقط
- حساب مجدول للحذف: «حسابك مجدول للحذف في {التاريخ}. هل تريد استعادته؟»

### قواعد تسجيل الدخول
- الرمز 4 أرقام عشوائية، صالح 5 دقائق، إعادة الإرسال بعد 60 ثانية، حد **5 رسائل في الساعة و20 في اليوم** للرقم، و**5 محاولات خاطئة تقفل الرقم 15 دقيقة** وتُسجل حدثًا أمنيًا؛ الرمز الجديد يبطل السابق.
- الجلسة تبقى حتى الخروج أو 90 يومًا بلا استخدام.
- حساب واحد بدورين: يبقى عميلًا ويستطيع التقدم ليصبح مؤجّرًا.



# المؤجّر

## شريط التنقل
 لوحتي، أماكني، التقويم، المهتمون، حسابي.





# صفحات الشروط و الاحكام (صفحات تقنية و قانونية)
على الويب فقط **صفحات تقنية و قانونية** يخدمها الخادم نفسه، بلا دخول ولا حجز، ونصوصها وبياناتها من لوحة الإدارة: الشروط، الخصوصية، سياسة النزاعات، طلب حذف الحساب، صفحة الدعم (جوال وواتساب وبريد الدعم، بلا نموذج)، صفحة المشاركة، وصفحات الخطأ والصيانة (القسم ٤٧).
