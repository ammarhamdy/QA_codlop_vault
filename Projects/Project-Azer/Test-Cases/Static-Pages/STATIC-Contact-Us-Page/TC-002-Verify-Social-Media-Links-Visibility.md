# Test Data
| Field         | Value                        |
| ------------- | ---------------------------- |
| Facebook Link | https://facebook.com/company |
| X Link        | https://x.com/company        |
| Instagram Link| https://instagram.com/company|
| TikTok Link   | https://tiktok.com/company   |

# Preconditions
- The Contact Us page is accessible.

# Steps
1. Navigate to the Contact Us page.
2. Locate the social media section.
3. Verify that the Facebook link/icon is visible.
4. Verify that the X (formerly Twitter) link/icon is visible.
5. Verify that the Instagram link/icon is visible.
6. Verify that the TikTok link/icon is visible.
7. Click on each social media link/icon and verify it opens the correct social media page in a new tab.

# Expected Result
- All specified social media links (Facebook, X, Instagram, TikTok) are visible and correctly displayed.
- Clicking each link successfully navigates to the associated social media platform's page in a new tab.

# Notes
- No JSON content was provided for social media links; test data is based on general expectations.
