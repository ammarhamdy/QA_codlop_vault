# Test Data
| Field         | Value                        |
| ------------- | ---------------------------- |
| Facebook Icon | Link to Facebook Page        |
| Twitter Icon  | Link to Twitter Profile      |
| LinkedIn Icon | Link to LinkedIn Profile     |

# Preconditions
- The website is accessible.
- Social media icons are present, typically in the footer or header.

# Steps
1. Navigate to any page on the website.
2. Locate the social media icons (e.g., in the footer).
3. Verify that all configured social media icons (e.g., Facebook, Twitter, LinkedIn) are visible and correctly rendered.
4. Click on each social media icon.
5. Verify that each click opens the correct social media profile/page in a new browser tab or window.

# Expected Result
- All social media icons are visible and visually correct.
- Clicking each icon successfully navigates to the associated social media platform's page.
