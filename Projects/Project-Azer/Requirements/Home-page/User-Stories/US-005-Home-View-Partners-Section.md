## Story Description
**As a** website visitor  
**I want to** view the partners section on the home page  
**So that** I can see the organizations and institutions collaborating with the platform

## Acceptance Criteria
- [ ] **Scenario 1:** Given the home page is loaded -> When the partners section is displayed -> Then the section title is visible
    
- [ ] **Scenario 2:** Given the home page is loaded -> When the partners section is displayed -> Then the section description is visible
    
- [ ] **Scenario 3:** Given partner logos are configured -> When the partners section is displayed -> Then all partner logos are visible
    
- [ ] **Scenario 4:** Given a partner logo exists -> When the partners section is displayed -> Then the logo is displayed correctly without distortion or truncation
