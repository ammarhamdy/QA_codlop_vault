## Story Description
**As a** website visitor  
**I want to** view frequently asked questions and answers  
**So that** I can quickly find answers to common inquiries

## Acceptance Criteria
- **Scenario 1:** Given the Contact Us page is loaded -> When the FAQ section is displayed -> Then all configured questions are visible
    
- **Scenario 2:** Given the Contact Us page is loaded -> When a question is displayed -> Then its corresponding answer is visible
    
- **Scenario 3:** Given FAQ entries exist -> When the FAQ section is displayed -> Then each FAQ item contains both a question and an answer
